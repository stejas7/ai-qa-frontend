# Video 1 — AI UAT Engineer Product Overview

**Target length:** 2:30–3:00
**Format:** 16:9, 1080p
**Audience:** Engineering leaders, QA/UAT teams, product owners, buyers, interview/demo viewers
**Purpose:** Explain what AI UAT Engineer is, the problem it solves, and the end-to-end flow in one short video.

## Core message
AI UAT Engineer turns a business requirement into evidence-backed UAT and a release decision by coordinating a bounded workforce of specialist AI agents. Humans keep policy and release authority; agents automate analysis, test design, execution, evidence and recommendations.

## Scene-by-scene storyboard

### Scene 1 — Hook | 0:00–0:12
**Visual:** Product landing page. Slow zoom toward the AI UAT ENGINEER brand and product statement.
**On-screen text:** `From requirement → release confidence`
**Voice-over:**
“Software teams still spend hours turning requirements into test cases, running UAT, collecting evidence, and deciding whether a release is safe. AI UAT Engineer compresses that workflow into one governed, evidence-backed mission.”

### Scene 2 — What the product is | 0:12–0:30
**Visual:** Open `/how-it-works`. Show the product-flow visual.
**On-screen text:** `Requirement • AI + RAG • Agents • Browser • Evidence • Decision`
**Voice-over:**
“AI UAT Engineer is an autonomous UAT platform built around Java 21, Spring Boot, Spring AI, RAG, PostgreSQL with pgvector, Playwright browser execution, React, Docker, GitHub Actions and AWS.”

### Scene 3 — Company and product setup | 0:30–0:50
**Visual:** Sign in, then Company Setup. Highlight Team, Products and Credentials.
**On-screen text:** `Company → Product → Environment → Credentials`
**Voice-over:**
“A company first creates its workspace, registers an approved UAT, QA or DEV environment, and attaches runtime credentials only when authentication is required. Product configuration stays tenant-scoped.”

### Scene 4 — Start a UAT mission | 0:50–1:15
**Visual:** Start UAT page. Select product, upload a requirement document, show READY state, click Start UAT.
**On-screen text:** `1. Choose product  2. Upload requirement  3. Confirm  4. Start`
**Voice-over:**
“To start UAT, the user chooses the registered product, uploads a TXT, Markdown, DOCX or PDF requirement, confirms readiness and starts the mission. The platform resolves the company and target automatically.”

### Scene 5 — The AI workforce | 1:15–1:40
**Visual:** How It Works roadmap / agent activity. Animate a 100-agent catalog shrinking into a small specialist team.
**On-screen text:** `100-agent catalog • bounded specialist team`
**Voice-over:**
“The platform has a catalog of up to one hundred specialist AI agents, but it does not run all one hundred for every task. Mission planning selects only the specialists needed for risk, test design, security, performance, accessibility, data, evidence and release review.”

### Scene 6 — Execution and evidence | 1:40–2:05
**Visual:** Execution Details page. Show pass rate, latest execution, failed test example, screenshot/evidence link.
**On-screen text:** `Browser execution → screenshots → diagnostics → evidence`
**Voice-over:**
“Generated tests are executed against the target application. The platform records pass or fail status, duration, diagnostic information and evidence such as screenshots and traces, so every release recommendation can be reviewed.”

### Scene 7 — Release decision | 2:05–2:28
**Visual:** Results page. Show run status, test counts and APPROVED/BLOCKED decision.
**On-screen text:** `READY / BLOCKED`
**Voice-over:**
“The final result answers the most important question first: is this product ready to release? Test outcomes, requirement coverage and evidence feed a governed release decision. Human approval and override remain available where policy requires them.”

### Scene 8 — M1 to M100 | 2:28–2:48
**Visual:** M1–M100 roadmap visual.
**On-screen text:** `M1 → M100 • governed enterprise autonomy`
**Voice-over:**
“The product evolved from core UAT automation through enterprise integrations, reliability, adaptive test intelligence, business-journey analysis, workforce orchestration and enterprise autonomy governance.”

### Scene 9 — Close | 2:48–3:00
**Visual:** Return to landing page with Pricing and How It Works navigation visible.
**On-screen text:** `AI UAT Engineer — Hire digital UAT capacity when you need it`
**Voice-over:**
“The goal is simple: reduce manual UAT effort while increasing traceability, evidence quality and release confidence.”
