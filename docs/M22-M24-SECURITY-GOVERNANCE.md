# M22-M24 Frontend Security & Governance

The frontend now has a dedicated client for `/api/auth/capabilities` so future page actions can be rendered from server-declared permissions instead of duplicating role assumptions.

M22-M24 intentionally keep the visual flow simple while the backend becomes stricter. Platform governance/audit controls remain under the Platform workspace; tenant users continue to see only company-scoped product/UAT actions allowed by the backend.
